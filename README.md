# FinCoach — Personal Finance Coach

A single-page web app to track income, expenses, budgets, savings goals, and recurring subscriptions. Built with React and Vite. All data is stored in the browser (`localStorage`)—no account or backend required.

## Features

| Section | Description |
|---------|-------------|
| **Dashboard** | Monthly income, expenses, savings, balance, budget progress, recent transactions, goal progress, and upcoming bills |
| **Transactions** | Add, search, filter, sort, and delete income/expense records with categories |
| **Budgets** | Set monthly spending limits per category with safe / warning / exceeded alerts |
| **Goals** | Create savings targets, track progress, and see how much to save per month to meet a deadline |
| **Subscriptions** | Track recurring bills (monthly/yearly), due dates, and log payments as transactions |
| **Analytics** | Bar, pie, and line charts plus rule-based spending tips |
| **Reports** | Monthly summary and CSV export |
| **Settings** | Profile name, currency, savings target, custom categories, JSON backup/import, reset to defaults |

## Tech stack

- **React 19** — UI
- **Vite 8** — dev server and production build
- **Chart.js** + **react-chartjs-2** — charts
- **lucide-react** — icons
- **localStorage** — persistence (no database)

## Getting started

### Prerequisites

- [Node.js](https://nodejs.org/) 18+ (LTS recommended)
- npm

### Install and run locally

```bash
cd "Personal Finance Coach"
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

### Other scripts

```bash
npm run build    # Production build → dist/
npm run preview  # Preview the production build locally
npm run lint     # Run ESLint
```

## Deployment

This app is a static site. After `npm run build`, deploy the `dist` folder to any static host (e.g. [Vercel](https://vercel.com), Netlify, GitHub Pages).

**Vercel (typical settings):**

| Setting | Value |
|---------|--------|
| Build command | `npm run build` |
| Output directory | `dist` |
| Install command | `npm install` |

Point the project root to the folder that contains `package.json`.

## Data & privacy

- Data lives only in **your browser** on that device.
- Clearing site data or using another browser/device starts fresh unless you **export a JSON backup** from Settings.
- There is no login, cloud sync, or bank integration—entries are manual.

## How it works (brief)

1. **App.jsx** holds shared state and saves each slice to `localStorage` when it changes.
2. **Transactions** are the main ledger; budgets and charts read expense totals from them.
3. **Subscriptions → Log payment** can add a matching expense and advance the next bill date.
4. **Goals** track saved amounts separately (Quick Save does not change the transaction balance).
5. **Insights** on Analytics are generated by rules in `calculations.js` (not AI/ML).
